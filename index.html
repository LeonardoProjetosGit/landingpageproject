3 Linguagens

HTML (HyperText Markup Language) é a linguagem de marcação utilizada para estruturar o conteúdo de uma página web. Com ela, definimos elementos como títulos, textos, imagens, links, formulários e outras partes que compõem a estrutura de um site.

CSS (Cascading Style Sheets) é utilizado para definir a aparência e o layout das páginas web. Ele permite trabalhar com cores, fontes, espaçamentos, tamanhos, posicionamento dos elementos e responsividade, deixando a página mais organizada e visualmente agradável.

JavaScript é uma linguagem de programação utilizada para adicionar interatividade e comportamentos dinâmicos às páginas web. Com ela, é possível criar recursos como menus interativos, validação de formulários, animações, alterações de conteúdo e comunicação com APIs.

3 Desenvolvedores

Entenda quem são!

Programador Front-end

É responsável pelo desenvolvimento da parte visual e interativa de uma aplicação, ou seja, aquilo que o usuário vê e utiliza. Trabalha com tecnologias como HTML, CSS e JavaScript, buscando criar interfaces organizadas, responsivas, acessíveis e com uma boa experiência de navegação.

Programador Back-end

É responsável pelo desenvolvimento da parte que funciona por trás da interface da aplicação. Ele trabalha com regras de negócio, processamento de dados, bancos de dados, APIs, autenticação e comunicação entre sistemas, garantindo que as funcionalidades da aplicação funcionem corretamente.

Programador Full-stack

Atua tanto no desenvolvimento Front-end quanto Back-end, sendo capaz de trabalhar desde a criação da interface que o usuário utiliza até a lógica, banco de dados e serviços que funcionam por trás dela. Por isso, possui uma visão mais ampla do desenvolvimento de uma aplicação e de como suas diferentes partes se conectam.
